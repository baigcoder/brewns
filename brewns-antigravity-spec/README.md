# Brewns-inspired Café Antigravity Build Pack

This folder contains a build-ready specification for recreating the **interaction language** of the public Brewns reference as an original café website.

## Files

- `ANTIGRAVITY_PROMPT.md` — paste this into Antigravity as the master build prompt.
- `PRD.md` — product requirements.
- `ARCHITECTUE.md` — architecture (requested filename spelling).
- `RULES.md` — non-negotiable implementation rules.
- `DESIGN.md` — design system + motion extraction.
- `TASKS.md` — phased implementation checklist + gates.
- `MEMORY.md` — project memory and reference facts.
- `ANTIGRAVITY_GITHUB_SKILLS.md` — skill selection and GitHub workflow.
- `AGENTS.md` — repository-level agent instructions.
- `.agents/skills/` — local Antigravity skill bundles.

## Source basis

Reference landing page: `https://brewns-coffee.vercel.app/`

Public design description: `https://www.templify.digital/layer/brewns`

Current Antigravity skill docs: `https://antigravity.google/docs/skills`
